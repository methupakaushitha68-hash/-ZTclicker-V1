# 💎 ZTclicker V1

A sleek, lightweight, and simple desktop auto-clicker built with **Python** and **CustomTkinter**. Designed for gamers and power users who need reliable left and right-clicking with customizable hotkeys and a clean dark-mode user interface.
---

## ✨ Features

* **Dual Clicker Support:** Independently control and configure both Left and Right clickers.
* **Customizable CPS (1-100):** Set your desired Clicks Per Second safely and efficiently.
* **Dynamic Hotkeys:** Easily change hotkeys for Left Click, Right Click, Stop All, and Window Hide/Show on the fly.
* **Stealth / Hide Mode:** Instantly hide or show the application window using a hotkey (`H` by default).
* **Modern UI:** Built using `CustomTkinter` featuring a gorgeous dark theme and glowing accents.
* **Safety First:** Dedicated "Stop All" hotkey (`X` by default) to halt clicking instantly.

---

## 🚀 Default Hotkeys

| Action | Default Key | Description |
| **Toggle Left Click**  - `R` - Starts/Stops Left Auto-Clicker 
| **Toggle Right Click** - `F` - Starts/Stops Right Auto-Clicker 
| **Stop All**           - `X` - Instantly stops all active clickers 
| **Hide / Show Window** - `H` - Hides or restores the application window
